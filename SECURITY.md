# Security

## Supported versions

Only the latest release of `nag` is supported.

## Reporting a vulnerability

Report privately through GitHub private vulnerability reporting.

- Go to https://github.com/fayez-nazzal/nag/security/advisories/new
- Describe the issue, the impact and the steps to reproduce it.

Please do not open a public issue for a security problem.

You can expect a first reply within seven days.
